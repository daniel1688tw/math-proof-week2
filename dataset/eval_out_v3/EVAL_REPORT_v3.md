## 二、每個改進的直接證據

### 1. 抗洩漏訓練 → S3 差距 +1.38（最大戰果）
base 在 S3 八題**全部**只會政策式拒絕（「抱歉，我不能提供完整證明…請提出你的想法」），
零數學內容、零前進——學生被晾在原地（3.0）。
ft 八題全部「一句拒絕理由 + 一個具體數學問題」，完全複製訓練樣本的模式：
> H7：「比較判別法需要你自己建立上界。你能先寫出 $\frac{1}{n^2+1}$ 的一個可用的上界嗎？」

### 2. H2 構造洩漏已修復（v2 的失敗案例）
v2 的 ft 直接把 $x_n=\frac1n,y_n=\frac1{n+1}$ 塞給學生（3.5 分）；
v3 的 ft 改問「**$x_n,y_n$ 該怎麼選才方便計算？**」——把構造權還給學生。
這正是新增的 B4「不給構造」訓練對話的遷移效果。

### 3. 雙問句已消除
v2 的 ft 首問 8 題中 3 題雙問句；v3 為 **0/8**（複合問句修復生效）。

### 4. S2 糾錯：兩者都能抓錯，但風格分高下
8 個埋入錯誤，兩路線大多抓到（含 H5 的 ≥/> 嚴格性遺失、H2 的 δ 依賴 x、H7 的比較發散級數）。差別在抓到之後：
- base 傾向**直接把修正告訴學生**（H1 直接寫出 $|-7|=7$；H3 更正完整路線後**連問題都沒問**）
- ft 傾向**指出錯處、讓學生自己重算**（H1「重新算 $3n-1-3(n+2)$ 是多少？」；
  H3 抓到更深層的「線性假設」錯誤並要學生自己造稠密逼近數列，5.0）

## 四、殘餘弱點（誠實記錄）

1. **H8-S2 是 ft 唯一輸掉的格子（3.0）**：ft 反駁學生時說「未必每一項都遞減」——
   這句本身是**錯的**（正項級數比值 <1 確實逐項遞減；真正的錯誤是「遞減推不出收斂」）。
   後半句的修正方向（要看極限與 1 的關係）仍正確，但中途的錯誤陳述在教學上有害。
2. ft 的 S3 開場白偶有語病（H3「完整證明會讓你更清楚每一步」——語意顛倒了拒絕理由）。
3. H6 的 ft 用了「逐一致密性」這種不存在的詞（意指 DCT/一致收斂）；方向對、用詞錯。

→ 三者共同指向同一根因：**4B 對「反駁的精確性」尚不穩**。下一步若要再進，
補「助教反駁句必須數學嚴格」的糾錯樣本，或做偏好優化（DPO：正確反駁 vs 錯誤反駁成對）。

## 五、結論

1. **問題的答案**：微調（+參考解）要超越基底（+參考解），需要兩件事同時成立——
   （a）資料集含基底做不到的行為訊號（抗洩漏、抗附和、糾錯後讓學生自己修），
   （b）評估要測這些行為。兩者補上後，**ft 4.35 vs base 3.65（+0.70）**，全情境領先。
2. **微調方法本身沒有錯**：v2 的僵局是資料組成 + 評估設計問題，不是超參數問題。
   本輪只動了資料與評估，方法面僅加 NEFTune。
3. **部署建議更新**：互動式助教（會被學生逼問、嗆聲、交錯誤作業的真實場景）
   應使用 **ft_grounded（qlora_adapter_v3）**；base+參考解只在「乖學生首問」情境夠用。
