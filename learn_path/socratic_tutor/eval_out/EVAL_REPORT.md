## 二、關鍵發現

1. **微調確實贏過 base（3.63 → 4.04）**：微調模型更常「點名正確定理 + 問一個聚焦問題 + 簡潔」。
   base 較囉嗦、常一次問多個問題，且偶有錯誤（見下）。

2. **微調模型有「自信給錯提示」的失敗模式**（improve.md 問題③說的風險，實測抓到 2/12）：
   - 第1題 ε-δ：叫學生「complete the square（配方）」——**錯**，這題是因式分解 |x²-4|=|x-2||x+2|，配方是誤導。
   - 第6題 均勻連續：直接叫學生用 Heine-Cantor 定理——這題要**證**的就是均勻連續，引用該定理近乎循環/洩漏。

3. **思考型模型路線（A-socratic、grounded）最好（4.42）**：思考鏈讓提示更可靠、問句更乾淨。
   這驗證 improve.md 的判斷：**一個還不錯的思考型模型 + 好 prompt，是零訓練成本的強基準**。

4. **grounded（解答在手）的優勢正好出現在「該出現的地方」**：
   - 第6題均勻連續：grounded 4.5 vs A-socratic 3 vs 微調 2.5——grounded 把學生推向「緊緻性」卻**不點破** Heine-Cantor；其他路線要嘛洩漏要嘛太空泛。
   - 易題上參考解加分有限（A-socratic 已夠好），所以總平均與 A-socratic 打平；但 grounded **更少洩漏、更少出錯**，難題與正確性敏感題上勝出。

5. **base 偶有實質數學錯誤**：第12題把「收斂的定義」寫成了 Cauchy 準則（|aₙ−aₘ|<ε），定義錯置。

## 四、多輪評估（grounded，平均 6.75/10）

逐題 6–8 分，但**每題只跑了 1 個老師回合**——模擬學生（同一顆 4B）常太早宣告 [DONE] 或一次回太多，
導致沒真正多輪。**多輪設定本身偏弱**（學生模型不夠像學生），分數僅供參考，不宜過度解讀。
若要可信的多輪評估，需要更強/更受控的「學生」模型。

## 五、結論與建議

- **方向正確**：grounded（解答在手）在「正確性 + 不洩漏」上最穩，是目標架構該走的路。
- **微調的價值有限且有風險**：比 base 好一點，但會自信給錯提示；單獨用微調模型當助教不安全。
- **投報率最高的組合**：**思考型模型 + grounded（參考解在手）**，不必微調就達到最佳且最安全。
  微調模型若要用，建議也走 grounded（餵參考解，見 inference.py 的 REF_FILE），用參考解擋住它的錯誤提示。
- **下一步**：
  1. 把 grounded 設為預設助教路線（guided_tutor.py）。
  2. 多輪評估換更強的「學生」與「裁判」模型，才能真正量「一步步引導到完成」。
  3. 微調若續做，針對「錯誤提示」案例補資料（如 ε-δ 不要配方、要證的定理不要直接引用）。

## 六、追加：第五方「微調 + grounded」組合評估

問題：把參考解餵給**微調模型**（gen_finetuned_grounded.py），會不會比只有 grounded（思考型）好？

### held-out 教學品質（我的評分，/5）

| 路線 | 平均 |
|---|:---:|
| 微調（純） | 4.04 |
| grounded（思考型，原最佳） | 4.42 |
| **微調 + grounded** | **4.54**（最佳）|

### 關鍵：grounding 修好了微調模型的兩個失敗案例

| 題 | 微調（純） | 微調 + grounded |
|---|---|---|
| ε-δ x²=4 | 「配方(complete the square)」← 錯，2分 | 「該如何界定 \|x²-4\|」← 正確，4.5分 |
| 均勻連續 | 直接叫用 Heine-Cantor ← 洩漏/循環，2.5分 | 引導「用各點 δ 建構開覆蓋」← 教真正證明，4.5分 |

參考解在 context 裡，模型就不再亂給配方、也不把要證的定理當黑盒丟出；另也把數個囉嗦答案理順
（Lipschitz 3.5→4.5）。僅 2 題微幅退步（把界限直接給學生、問句稍鈍）。

### 結論與權衡

- **品質**：微調+grounded (4.54) ≥ grounded思考型 (4.42) ＞ 微調純 (4.04)。差距小（12 題雜訊內），
  穩健結論是「**至少一樣好，且修掉了危險的錯誤提示**」。grounding 同時拿到微調的對題風格 + 參考解的正確性。
- **操作複雜度**：微調+grounded 需**兩顆模型**（思考型產參考解 → transformers 微調模型引導），
  6GB 上要 GPU 接力、部署較麻煩；好處是引導回合無思考鏈、較快。grounded 思考型則**一顆模型**走完、最簡單。
- **建議**：要最簡單可靠 → best_grounded_tutor（思考型 grounded）；要最高品質且能接受兩模型流程
  → 微調 + grounded（inference.py 設 REF_FILE 餵參考解）。**無論哪個，grounding（參考解在手）都是關鍵。**
