## 二、最重要的發現：難題上「純微調」會主動變差

純微調在 v4 是**最差**（2.90），甚至低於 base（3.30）。原因是它在難題上**自信地給錯方向**：

| 題 | 純微調的錯誤提示 |
|---|---|
| 矩消失⇒f≡0 | 叫學生「用多項式逼近 **Dirac delta**」——錯，標準證明是用 Weierstrass 逼近 f 本身 |
| Poincaré 不等式 | 叫用「分部積分」——路線錯亂，正解是 FTC + Cauchy-Schwarz |
| ∑aₙ收斂⇒∑√aₙ/n | 「aₙ<1 ⇒ √aₙ/n < 1/n」——**死路**（∑1/n 發散），正解是 Cauchy-Schwarz |
| f+f'→L | 「乘以 e^{-x}」——**符號錯**（應乘 eˣ：(eˣf)'=eˣ(f+f')）|
| ∫\|f''\|≥4max\|f\| | 「∫f''=f(1)−f(0)=0」——**數學錯誤**（∫f''=f'(1)−f'(0)）|

行為遷移訓練（小學數學）讓它「敢講具體方法」，但 4B 缺乏微積分深度，難題上這些方法常是錯的。
→ **單獨用微調模型當難題助教不安全**，這是目前最強的證據。

## 三、grounded 在難題上的優勢比中等題更大

- 難題 grounded 4.55 vs base 3.30（差 1.25）；held-out 只差 0.79。
- **題目越難、base 自身知識越不夠，參考解（答案卡）的價值越大。** 同樣那 5 題純微調給錯的，
  grounded 全部給對（Cauchy-Schwarz、Weierstrass、FTC、g=f−L 化簡、max 在內部點）。

## 四、grounding 修好微調、但有一次崩潰

finetuned_grounded（4.10）把純微調的錯誤提示**幾乎全修好**（矩/Poincaré/級數/∫f'' 那幾題都變正確），
單看其餘 9 題平均約 4.5、與 grounded 並駕齊驅。但 **Landau 那題出現退化回應**：

> finetuned_grounded 對 Landau 題回了「**Hi . Can you explain your idea?**」——空泛、無數學、形同放棄。

這顯示微調的 Instruct 模型在「很長的 grounded prompt + 難題」下偶爾會崩潰（拉低 0.45 分）。
是 微調+grounded 組合的**穩健性隱憂**。

## 五、結論

1. **難題讓結論更清楚**：grounded（思考型 + 參考解）最好且最穩；純微調最差且危險。
2. **參考解（grounding）是關鍵**，題目越難越重要——它擋住小模型的錯誤提示。
3. **純微調在難題上反而有害**（自信給錯方向）；要用微調就**務必** grounding。
4. **建議**：難題場景優先用 best_grounded_tutor（單一思考型模型、最穩）。
   微調+grounded 品質相近但有崩潰風險與兩模型複雜度，需先解決長 prompt 穩健性再考慮。
