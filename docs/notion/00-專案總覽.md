## 一句話

一個**不給答案、只引導**的高等數學證明助教：學生貼上任何一道證明題，
助教**先自己把它證一遍並驗證過**才開口教；證不出來就誠實說沒把握，
改用同學身分一起想；教到學生寫出證明為止，寫完就收手。

## 核心設計原則（三次失敗換來的）

> **離散決策交給程式碼；內容拿捏交給預寫內容；模型只負責數學與語氣。**

具體分工：

1. **何時升級提示、何時換階段** → 確定性 Python（`tutor_driver.py`）
2. **提示深度、審閱重點** → 預寫內容（參考解、hint ladder、教學步驟）
3. **即時數學判斷**（證明對不對、草稿缺什麼）→ 思考型模型，**永遠在幕後**
4. **把判斷包裝成引導語氣** → 微調的 4B 模型

第 3 點是 2026-07-12 的混合架構延伸：思考型模型單獨面對學生會出事
（曾把完整證明整段交出、有空輸出），所以只讓它幕後找碴。
