## 匯入方式（三選一）

### 方式 A：整包匯入（推薦）

1. 把 `docs/notion/` 這個資料夾壓成 zip
2. Notion 左側欄 → **Import** → **Markdown & CSV** → 選 zip
3. Notion 會為每個 `.md` 建立一個頁面

匯入後手動整理階層：把 `00-專案總覽` 拖到最上層，其餘 01–09 拖進它底下當子頁，
然後在總覽頁的「頁面導覽」表格裡把文字換成 Notion 內部連結（`@` 提及頁面）。

### 方式 B：逐頁貼上

開一個新頁面 → 直接貼上 `.md` 內容。Notion 會自動轉換標題、表格、程式碼區塊。
適合只想放其中幾頁的情況。

### 方式 C：等連接器授權後由 Claude 直接建立

Notion 連接器需要在 claude.ai 的連接器設定裡授權；授權完成後，
可以請 Claude 直接依這些檔案建立頁面結構，不必手動匯入。

## 匯入後建議的加工

| 加工 | 為什麼 |
|---|---|
| 把「頁面導覽」表格改成 Notion 內部連結 | 方便跳轉 |
| 在總覽頁加一個 **Database**：「迭代紀錄」 | 每次訓練／守門一列（日期、版本、判定、依據文件），比 markdown 表格好維護 |
| 在「08 已知弱點」建成 **Board / Table** | 弱點可以標 status（未開始／進行中／已解決）與 priority |
| 加 Toggle 收折長表格 | 02、09 兩頁表格較長 |

## 維護建議

這份整理是 **2026-07-28 的快照**。repo 內真正的權威來源是各分支的 `CLAUDE.md`
（每次迭代都會更新）。建議的同步節奏：

- **每次守門通過並推送後** → 更新「07 分支地圖」與「08 已知弱點」
- **每次訓練實驗結束（不論採用與否）** → 在「05 決策與判定紀錄」加一列
- **架構有實質改動時** → 更新「01 系統架構」與「02 核心檔案地圖」
