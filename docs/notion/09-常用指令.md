## 推送前守門（每次更新必跑；skill `/pre-push-check`）

```powershell
python dataset\regression_suite.py --quick     # 單元+資料集（~1 分鐘）
python dataset\regression_suite.py             # 完整（~1.5–2hr）
python dataset\regression_suite.py --gen-only  # 只生成不評審
python dataset\regression_suite.py --rejudge   # 讀存檔重評（不重跑 GPU）
```

退出碼：`0` 通過｜`1` 退步（**不可推送**）｜`2` 評審不完整（`--rejudge` 補評）

## 環境變數速查

| 變數 | 預設 | 作用 |
|---|---|---|
| `PYTHONNOUSERSITE=1` | — | 防使用者 site-packages 洩漏（**執行前建議必設**）|
| `FINAL_ADAPTER` / `HELDOUT_ADAPTER` / `HARD_ADAPTER` / `XDOMAIN_ADAPTER` | `qlora_adapter_v9` | 覆寫各 runner 用的 adapter |
| `REVIEW_BACKSTOP` | `1` | 設 `0` 關閉審閱後盾 |
| `REVIEW_MODEL` | `qwen3-4b-thinking-2507:latest` | 備課／後盾用的 Ollama 模型 |
| `OLLAMA_URL` | `http://localhost:11434/api/chat` | Ollama 端點 |
| `PROVER_K` | `3` | 備課生成幾份候選參考解 |
| `JUDGE_BACKEND` | `antigravity` | `antigravity`｜`claude`｜`gemini` |
| `AGY_MODEL` | `"Gemini 3.6 Flash (Medium)"` | 評審模型 |
| `JUDGE_SAMPLES` | `3` | Tier 2 每則探針評審次數（取共識）；`1` 還原舊行為 |
| `JUDGE_EPSILON_OVERRIDE` | — | 逐指標容忍度覆寫 |
| `REMOTE_GEN_SSH` | — | 遠端推論（大模型放伺服器 GPU）|
| `MODEL_NAME` | — | 換基底模型（伺服器訓練用）|
| `VERIFY` | `0` | BoN 驗證器（`0` = 現行部署） |

## 跑守門前的例行檢查（6GB 卡）

```powershell
ollama stop                                    # 釋放後盾模型佔用的 3.2GB
taskkill /F /IM "Antigravity.exe"              # 關 IDE（背景進程搶 GPU）
taskkill /F /IM "Antigravity IDE.exe"
nvidia-smi                                     # 確認顯存已釋放
```

⚠️ **連續跑多輪 2 小時守門後，walkthrough 探針處會出現進程層死結**（兩次重現）。
判斷「卡死 vs 只是慢」用 **CPU 時間增量**：40 秒內 <0.5 秒＝卡死，>5 秒＝在算。
排除方式 `Stop-Process -Force`，但**建議讓機器休息後再跑，不要立刻重試**。
