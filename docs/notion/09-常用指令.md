## 推送前守門（每次更新必跑；skill `/pre-push-check`）

```powershell
python dataset\regression_suite.py --quick     # 單元+資料集（~1 分鐘）
python dataset\regression_suite.py             # 完整（~1.5hr）
python dataset\regression_suite.py --gen-only  # 只生成不評審
python dataset\regression_suite.py --rejudge   # 讀存檔重評（不重跑 GPU）
python dataset\regression_suite.py --update-baseline   # 確認進步後抬基準
python dataset\auto_gate.py --max-iters 3      # 外圈自動迭代
```

退出碼：`0` 通過｜`1` 退步（**不可推送**）｜`2` 評審不完整（`--rejudge` 補評）

## 環境變數速查

| 變數 | 作用 |
|---|---|
| `PYTHONNOUSERSITE=1` | 防使用者 site-packages 洩漏（**執行前建議必設**）|
| `FINAL_ADAPTER` / `HELDOUT_ADAPTER` / `HARD_ADAPTER` / `XDOMAIN_ADAPTER` | 覆寫各 runner 用的 adapter |
| `REVIEW_BACKSTOP=0` | 關閉審閱後盾 |
| `JUDGE_BACKEND` | `antigravity`（預設）｜`claude`｜`gemini` |
| `AGY_MODEL` | 預設 `"Gemini 3.6 Flash (Medium)"` |
| `JUDGE_EPSILON_OVERRIDE` | 逐指標容忍度覆寫 |
| `REMOTE_GEN_SSH` | 遠端推論（大模型放伺服器 GPU）|
| `MODEL_NAME` | 換基底模型（伺服器訓練用）|
| `VERIFY=0` | BoN 驗證器關閉（現行部署）|
