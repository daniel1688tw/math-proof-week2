## 資料集建置

| 檔案 | 職責 |
|---|---|
| `dataset/src/` | 中文內容源碼：`problems_A~E.py`（50 題）、`dialogues_*.py`（對話） |
| `dataset/src_en/` | 英文平行版本 |
| `dataset/build.py` | 由 `src/` 建置出 `problems.json`、`train.jsonl`、`val.jsonl` |
| `dataset/validate.py` | 資料集格式與內容驗證 |
| `dataset/test_dataset.py` | 資料集測試 |

`src/` 內的對話檔分工：

| 檔案 | 針對的行為 |
|---|---|
| `dialogues_A~E.py` | 五類題型的主線引導對話 |
| `dialogues_aug_A~E.py` | 增強樣本 |
| `dialogues_hint.py` | 分級提示 |
| `dialogues_resist.py` | 抗逼問（拒絕直接給答案） |
| `dialogues_rhythm.py` | 對話節奏 |
| `dialogues_writeup.py` | 請學生寫證明與審閱 |
| `dialogues_altmethod.py` | 順著學生自己的方法走（不強拉回標準解） |
| `dialogues_journey.py` | 跨題型「剛學完但易卡住」旅程（**已寫入但尚未成功上線**，見 05） |
