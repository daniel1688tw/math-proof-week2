# 06 商品化介面

> 分支：`feature/product-ui`（基底 `training-iter-v11`）
> 形態：Gradio **本機單人 Demo**，使用者自帶題目
> 更新日期：2026-08-07

---

## 啟動

```powershell
pip install "gradio>=4.44"                                              # 首次
conda run -n lora_project --live-stream python dataset\app.py
# 終端出現「[app] 模型就緒，啟動介面 http://localhost:7860」後開瀏覽器
```

首次載入模型約 30–60 秒。介面綁定 `127.0.0.1:7860`，**只接受本機連線**；
`demo.queue(default_concurrency_limit=1)` ＝同一時間只處理一個請求（單張 6GB 卡）。

前置：Ollama 需在線（備課依賴它）。離線時介面頂端會警告，且**所有題目都走同學模式**。

---

## 使用流程

```
貼上題目敘述（必填）＋ 目前的證明嘗試（可留空）
        │
        ▼  按「開始備課」
   逐階段串流顯示：PROVER 1/3 → VERIFIER 候選1 → REPAIR → SEGMENTER → LADDER
        │
        ▼
   ✅ verified   → grounded 引導教學（全部防護生效，含自動生成的分級提示梯）
   ⚠️ unverified → 同學模式（誠實聲明沒把握）
        │
        ▼  對話區逐輪互動，助教不給答案、只引導
        │
        ▼  「重新開始（換一題）」清空對話回到輸入畫面
```

生成期間**同時停用「送出」鈕與輸入框**（只停用按鈕的話按 Enter 照樣送出）。

題目 id 固定為 `USER`，完全不查任何題庫。

## 程式結構（217 行）

| 區塊 | 內容 |
|---|---|
| **純邏輯**（可單元測試，不載模型、不連 Ollama） | `check_ollama()`／`assemble_problem()`／`opener_for()` |
| **備課串流** | `_run_prepare()`：背景執行緒 + 佇列，逐階段 yield 進度；worker 用 try/finally 保證送出結束哨兵，備課例外不會讓 UI 永久卡死 |
| **Gradio UI** | `build_ui(tok, model)`：輸入區 → 進度 → 對話區 |

`assemble_problem()` 會把備課產出的 `hint_ladder` 一併傳給 driver
（LADDER 驗收不過時該鍵不存在，driver 走通用保底句）。

## 已做的健壯性處理

| 項目 | 作法 |
|---|---|
| 進行中停用按鈕 | 防單 GPU 佇列被連點塞爆；送出鏈同時停用 `send_btn` 與 `msg_tb`（Enter 重送也擋住） |
| 備課例外 | worker try/finally + 結束哨兵，錯誤回報而非卡死 |
| 開場生成例外 | `TutorDriver(...)` + `driver.start()` 包 try/except，失敗保留輸入態並友善回報 |
| 逐輪生成例外 | `on_send` 包 try/except，回一句友善訊息而非中斷 |
| Ollama 偵測 | 啟動時判定並在介面上警告 |

## 仍待手動驗收

真模型＋Ollama＋瀏覽器下的四情境（自動測試涵蓋不到 UI 互動層）：

1. 只有題目 → 逐級引導
2. 錯誤證明 → 糾正
3. Ollama 離線 → 同學模式
4. 重新開始 → 換題

**新增第 5 項（LADDER 上線後）**：自帶題目連續卡住 4 輪 → 確認等級 2 出現兩條**不同**的
具名提示，第 4 次卡住才進逐步教學（不是第 3 次）。

## 已知限制

- **守門照不到這條路徑**：Tier 1/2 是單輪探針、Tier 3 對話，全部走內建題（有手寫梯），
  LADDER 改動在守門指標上是**隱形的**。驗證只能靠 Tier 0 斷言 ＋ 人工檢視。
- **生成的提示梯未經人工審閱即用於教學**（不像 `reference_proof` 有 VERIFIER 獨立審）。
  緩解：提示保證不含算式、不洩漏參考解，且等級 2 的既有守衛在生成回覆時仍全數生效。
- **備課每題多一次 Ollama 呼叫**（LADDER，最長 300 秒）。
- **英文 session 會拿到中文提示內容**（備課只生繁中梯，回退順序是「英文梯 → 中文梯」）。
- **RTX 4050 6GB**：微調模型常駐約 3.5GB，備課時 Ollama 被擠到 CPU 而變慢——Demo 固有限制。
